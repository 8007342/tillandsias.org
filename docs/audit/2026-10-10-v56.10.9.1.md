## Flags re-decided

- **Phone: the installer reset is now soft on Linux and Windows.**
  - The Linux soft reset deletes no store, and sign-ins survive while the keyring unlocks.
  - Windows runs the same soft reset without prompting.
  - A new RED covers the Mac: at this release its reset still deletes the vault keys and the secret store, against the host-state-lifecycle requirement that every platform's reset be soft.
  - The PATH names the open pull request that rewrites it (#281 in the runtime repository). It is not in any release yet.
- **Power user: the project web sibling was rewritten.**
  - Publishing now goes through `local_web_preview.rs` and serves a selected document tree, never `.git`, `.env` or the forge root.
  - A departed lane's preview is stopped and its route removed.
  - The REDs "the repo root and `.git` are reachable" and "nothing reaps the sibling" are now GREEN.
  - The `~/src` RED no longer applies to publishing.
  - Live evidence, the publish litmus and the apex route remain RED.
- **Power user: other changes.**
  - `--reset-guest` no longer wipes the Vault store.
  - The model-cache GREEN was softened because the spec now runs ahead of the code.
- **Security: the reset GREEN is now RED.**
  - The Linux `--reset-state` keeps Vault credentials by design.
  - The clearer function is documented as uninstall-only and has no caller.
- **Security: the fallback-share RED is sharper.**
  - The vault spec now forbids a persisted fallback share.
  - The code still writes one.
- **Security: two RED/PATH pairs were added.**
  - Windows-tray tests write the real Credential Manager (runtime row `1562-uxhc`).
  - The installer-verification RED gets a PATH: the open Windows cosign row `1562-hsa8` and an install-entry-point row that already existed at the old pin. The old "no path recorded" sentence was wrong then too.
- **MathWiz:** two cited shell checks were ported to Lua (`check-requirement-ids`, `check-centicolon-ratchet`). Their footnotes were retargeted with new quotes. No claim changed state, and no PLAUSIBLE was upgraded.
