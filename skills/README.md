# Skills

Canonical home of the procedures an agent follows to keep this site honest.
One source of truth: every harness reaches a skill through a symlink into this
directory (`.claude/skills/<name>` and `.opencode/skills/<name>` point here), so
what an agent can do does not depend on which harness launched it. The
`openspec-*` skills under the harness directories are the exception: they are
generated by the `openspec` CLI at launch, not authored here.

| Skill | Use it when |
|---|---|
| [`update-website`](update-website/SKILL.md) | Weekly, or after a Tillandsias release: re-verify the pages against the newest release and move the pins. The bootstrap. |
| [`audit-site-claims`](audit-site-claims/SKILL.md) | Re-verifying one level's footnotes, quotes and flags against a checkout at a given tag, with an adversarial second pass. |
| [`file-findings`](file-findings/SKILL.md) | Recording what the audit found so it survives the forge, and getting it in front of the runtime project. |

Helper scripts are POSIX shell over `git`, `curl`, `jq` and the existing build;
no new Python (the runtime methodology forbids it for committed automation, and
this repository's only Python is the page build it inherited). Every script
prints a one-line machine-readable verdict on its last line and exits non-zero
on anything that should stop a publish.
